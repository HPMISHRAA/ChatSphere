# ChatSphere

ChatSphere is a modern, real-time messaging application with seamless responsiveness and professional UI, ready for immediate team communication.

## Features
- Real-time messaging with Socket.IO
- Room creation and joining
- Last Seen and Online Presence
- Dark/Light Theme
- Persistent messages and notifications

## Tech Stack
- MongoDB
- Express.js
- React.js
- Node.js
- Tailwind CSS
